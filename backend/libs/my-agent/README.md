# MyAgent Module

A NestJS module for the MyAgent functionality.

## Overview

This module provides MyAgent capabilities for the Pietra AI API.

## Usage

```typescript
import { MyAgentModule } from '@app/my-agent';

@Module({
  imports: [MyAgentModule],
})
export class YourModule {}
```

## Development

This module is part of the Pietra AI API libs structure and follows the standard NestJS module patterns.
