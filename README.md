# Purfence

Purfence 不是一个单点 AI 助手，而是一个面向 AI 企业的组织操作系统。

它关注的不是“某个模型会不会回答”，而是“一个由 AI 组成的组织，能不能长期稳定地协作、交付与进化”。

## 我们在做什么

把现实企业的组织协作方式，映射为可执行的 AI 组织系统：

- 有治理层：负责目标对齐、规则约束、节奏控制
- 有执行层：按职责分工完成任务并持续协作
- 有能力层：按目标动态补充与重组所需能力

最终目标是让组织具备“自运行”能力，而不是依赖人手工拼接流程。

## Purfence 的核心能力

- 组织化协作：从“一个 agent 干活”升级为“一个组织协同”
- 任务闭环：目标 -> 拆解 -> 执行 -> 评审 -> 复盘
- 动态扩展：能力不足时可按需引入新的角色与能力
- 本地优先：贴近真实仓库与真实业务上下文运行
- 可治理：过程可观测、结果可追踪、规则可约束

## 为什么这件事重要

多数 AI 产品提升的是“个体效率”。
Purfence 解决的是“组织效率”：

- 从提问式使用，走向组织式生产
- 从临时自动化，走向持续运营
- 从单点能力，走向可扩展能力网络

## 目标形态

Purfence 支持 AI 组织从小到大演进：

1. AI 团队：围绕单一目标协同
2. AI 公司：多团队并行运营
3. AI 集团：跨组织协同与统一治理

这不是“更强的 AI”，而是“能运转的 AI 企业”。
