# Inputs 模板

## idea.md

记录用户的原始需求/点子。

```markdown
# Idea

## 需求描述（原文）

标题：[需求标题]

[用户的原始需求描述]

## 附加信息（可选）

- 目标用户：[如果用户提供了]
- 约束条件：[如果用户提供了]
- 偏好：[如果用户提供了]
```

## user_answers.md

记录用户对澄清问题的回答。

```markdown
# User Answers

用于记录对"澄清问题"的用户回答。

## Q1: [问题标题]

[用户的回答]

## Q2: [问题标题]

[用户的回答]

---

如果没有需要回答的问题，写：None
```

## 使用说明

- `idea.md` 由系统在 Issue 创建时自动生成
- `user_answers.md` 在用户回答开放问题后更新
- PM 读取这两个文件了解需求上下文
