## 写作指南

### 页面 ID

- 每个页面使用稳定 ID：`P1`、`P2`、`P3`...
- 在站点地图和页面详情中保持一致

### 区块组成

描述页面的主要组成部分：

- **Header**：顶部区域（导航、标题、操作按钮等）
- **Sidebar**：侧边栏（如果有）
- **Main**：主内容区
- **Footer**：底部区域（操作按钮、分页等）

### 关键状态

每个页面必须考虑以下状态：

| 状态 | 说明 | 必须考虑 |
|-----|------|---------|
| loading | 数据加载中 | ✅ |
| empty | 无数据 | ✅ |
| error | 加载失败 | ✅ |
| success | 正常展示 | ✅ |
| 其他业务状态 | 根据业务需要 | 按需 |

### 与 PRD 的关系

- IA 是 PRD 功能清单的视觉化表达
- 每个页面应该能对应到 PRD 中的功能点
- 如果某个功能在 IA 中找不到对应页面，说明 IA 不完整
