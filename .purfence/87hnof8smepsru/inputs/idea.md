# Idea

## 需求描述（原文）

**标题**：检查更新功能异常 - 无法检测到新版本

## 问题描述

检查更新功能异常，无法检测到新版本。

**现象**：
- 当前应用版本：v0.4.12
- 最新发布版本：v0.4.14
- 点击"检查更新"显示"已是最新版本"
- 实际上已经有新版本发布了

## 复现步骤

1. 使用 v0.4.12 版本的 Purfence
2. 点击"检查更新"
3. 显示"已是最新版本"
4. 但实际上 v0.4.14 已经发布

## 需要排查的问题

1. **更新检测 API 是否正确**：
   - 检查是否正确调用 GitHub Releases API
   - 检查 API 返回的数据格式是否正确

2. **版本比较逻辑是否正确**：
   - v0.4.12 vs v0.4.14 的比较是否正确
   - 版本号解析是否有问题

3. **缓存问题**：
   - 是否有缓存导致没有获取最新版本信息

4. **网络问题**：
   - 是否因为网络问题无法获取最新版本

5. **API 限制**：
   - GitHub API 是否有频率限制
   - 是否需要认证

## 验收标准

- [ ] 检查更新能正确检测到新版本
- [ ] 版本比较逻辑正确（0.4.12 < 0.4.14）
- [ ] 当有新版本时提示用户更新
- [ ] 提供下载链接或自动下载更新

## 优先级

**P0（高优先级）** - 用户无法获取最新版本，影响更新体验
