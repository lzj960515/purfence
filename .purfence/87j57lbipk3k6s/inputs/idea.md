# Idea

## 需求描述（原文）

**标题**：将 delegate task 工具的能力复刻到紫微

## 背景

天机团队在执行需求时，使用 **delegate task** 工具来调用各种后端能力（文件操作、代码搜索、命令执行等）。这些工具能力目前只在 delegate task 工具内部可用。

紫微（Purfence 的对话前台）目前缺少这些基础能力，导致无法直接处理一些文件操作、代码搜索等任务。

## 目标

让后端团队（通过 delegate task 工具工作的团队）**将自己现有的所有工具能力 1:1 复刻到紫微**，使紫微也能拥有这些工具能力。

## 实现方式

### 1. 调研阶段
- 后端团队探索自己使用的 delegate task 工具中有哪些工具
- 记录每个工具的：
  - 工具名称
  - 工具描述
  - 参数定义（名称、类型、是否必需）
  - 返回值格式
  - 内部实现逻辑（如果是自己实现的）

### 2. 复刻阶段
- 在 Purfence 项目中创建对应的工具
- 保持与 delegate task 工具中的工具 1:1 一致：
  - 参数名称、类型、格式一致
  - 返回值格式一致
  - 工具描述一致
  - 内部逻辑尽可能一致

### 3. 验证阶段
- 测试复刻的工具是否与原工具行为一致
- 确保紫微可以正常调用这些工具

## 验收标准

- [ ] 完成 delegate task 工具中所有工具的调研和记录
- [ ] 在 Purfence 中复刻所有工具
- [ ] 工具参数、返回值、描述与原工具 1:1 一致
- [ ] 紫微可以正常调用所有复刻的工具
- [ ] 通过测试验证功能一致性

## 优先级

**P1（中高优先级）**
