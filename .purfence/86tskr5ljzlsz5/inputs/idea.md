# Idea

## 需求描述（原文）

**标题**：优化自动更新交互方式 - 设置页检查+直接弹窗提醒

## 背景

当前自动更新功能存在白屏问题，且交互方式需要优化。

## 需求变更

### 1. 移除侧边栏 Logo 旁的更新按钮
- 删除 `AppSidebar.tsx` 中 Logo 旁边的更新按钮/铃铛图标
- 不再在侧边栏显示任何更新状态指示器

### 2. 设置页面新增检查更新按钮
- **位置**：设置 -> 通用
- **新增按钮**："检查更新"
- **功能**：用户主动点击后检查是否有新版本
- **结果**：
  - 无新版本：显示"当前已是最新版本"
  - 有新版本：弹出更新对话框

### 3. 保留自动检查逻辑（不变）
- ✅ 启动时自动检查（延迟 5 秒）
- ✅ 定时检查（每 2 小时）
- 检查逻辑保持不变

### 4. 修改发现新版本时的行为

**之前**：侧边栏显示"有新版本"按钮，用户点击后弹窗  
**现在**：**直接弹出更新对话框**

### 5. 更新弹窗三个按钮

```
┌─────────────────────────────────────┐
│           发现新版本                 │
│                                     │
│  当前版本: v0.2.8                   │
│  最新版本: v0.2.9                   │
│                                     │
│  更新内容:                          │
│  - xxx 功能                         │
│  - xxx 修复                         │
│                                     │
│   [更新]  [跳过此版本]  [稍后]      │
└─────────────────────────────────────┘
```

**按钮功能**：
- 🔄 **更新** - 开始下载新版本
- ⏭️ **跳过此版本** - 忽略此版本，不再提醒（记录到本地存储）
- ⏰ **稍后** - 关闭弹窗，下次定时检查时再提醒

### 6. 跳过版本逻辑
- 用户点击"跳过此版本"后，该版本不再弹窗提醒
- 存储方式：`localStorage.setItem('skippedVersion', 'v0.2.9')`
- 下次检查时对比：如果最新版本 === 跳过版本，则不弹窗
- 如果发布了更新的版本（如 v0.2.10），仍然弹窗提醒

## 涉及文件

### 前端
- `frontend/src/components/AppSidebar.tsx` - 移除更新按钮
- `frontend/src/pages/settings/GeneralSettings.tsx` - 新增检查更新按钮
- `frontend/src/components/update/UpdateDialog.tsx` - 修改按钮为三个
- `frontend/src/hooks/useUpdate.ts` - 添加跳过版本逻辑

### 可能的问题
- 需要先修复白屏问题才能测试
- 跳过版本需要持久化存储

## 验收标准

- ✅ 侧边栏 Logo 旁边不再显示更新按钮
- ✅ 设置-通用页面有"检查更新"按钮
- ✅ 点击检查更新按钮能正确检查并显示结果
- ✅ 启动时和定时检查自动弹窗（有新版本时）
- ✅ 弹窗有三个按钮：更新/跳过此版本/稍后
- ✅ 点击"跳过此版本"后不再提醒该版本
- ✅ 点击"稍后"后下次检查时仍然提醒
- ✅ 发布更新的版本后仍然弹窗提醒

## 优先级

**P0（高优先级）** - 修复白屏问题，优化用户体验
